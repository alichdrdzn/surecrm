## نصب و راه‌اندازی

### پیش‌نیازها

قبل از شروع نصب، اطمینان حاصل کنید که سیستم شما دارای نرم‌افزارهای زیر باشد:

| نرم‌افزار | حداقل نسخه | توضیحات |
|-----------|-------------|---------|
| [Node.js](https://nodejs.org/) | v18.x یا بالاتر | محیط اجرای JavaScript |
| [npm](https://www.npmjs.com/) | v9.x یا بالاتر | مدیر بسته‌های Node.js (همراه Node.js نصب می‌شود) |
| [MongoDB](https://www.mongodb.com/) | v5.x یا بالاتر | پایگاه داده NoSQL |
| [Git](https://git-scm.com/) | آخرین نسخه | برای کلون کردن مخزن (اختیاری) |

> **نکته:** اگر از macOS استفاده می‌کنید، توصیه می‌شود از [Homebrew](https://brew.sh/) برای نصب Node.js و MongoDB استفاده کنید.

### مراحل نصب

#### ۱. کلون کردن مخزن

```bash
git clone <repository-url>
cd surecrm
```

#### ۲. نصب وابستگی‌های بک‌اند

```bash
cd server
npm install
```

#### ۳. نصب وابستگی‌های فرانت‌اند

```bash
cd ../frontend
npm install
```

#### ۴. تنظیم فایل محیط (Environment)

یک فایل به نام `.env` در پوشه `server` ایجاد کنید و تنظیمات زیر را اضافه کنید:

```env
# پورت سرور
PORT=5000

# اتصال به MongoDB
MONGO_URI=mongodb://localhost:27017/surecrm

# کلید JWT (یک کلید تصادفی و امن انتخاب کنید)
JWT_SECRET=your-secret-key-here

# تنظیمات ایمیل (اختیاری)
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password

# آدرس سرور (برای CORS)
CLIENT_URL=http://localhost:3000
```

#### ۵. اجرای سرور بک‌اند

```bash
cd server
npm run dev
```

سرور بک‌اند به‌طور پیش‌فرض روی پورت `5000` اجرا می‌شود.

#### ۶. اجرای فرانت‌اند

در یک ترمینال جداگانه:

```bash
cd frontend
npm start
```

فرانت‌اند به‌طور پیش‌فرض روی آدرس `http://localhost:3000` اجرا می‌شود.

#### ۷. ساخت نسخه تولید (Production Build)

برای ساخت نسخه آماده انتشار:

```bash
# ساخت بک‌اند
cd server
# (نیازی به بیلد نیست، سرور اجرا می‌شود)

# ساخت فرانت‌اند
cd ../frontend
npm run build
```

فایل‌های بیلد شده در پوشه `frontend/build` قرار می‌گیرند.

#### ۸. نصب پکیج‌های سیستمی

برای اجرای SureCRM در محیط تولید، نیاز به نصب برخی پکیج‌های سیستمی دارید.

##### نصب MongoDB

```bash
# Ubuntu/Debian
wget -qO - https://www.mongodb.org/static/pgp/server-7.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt update
sudo apt install -y mongodb-org
sudo systemctl enable mongod
sudo systemctl start mongod
```

##### نصب Nginx

```bash
sudo apt update
sudo apt install -y nginx
```

##### تنظیم فایل Nginx

یک فایل کانفیگ در `/etc/nginx/sites-available/surecrm` ایجاد کنید:

```nginx
server {
    listen 80;
    server_name your-domain.com;

    root /home/chd/surecrm/frontend/build;
    index index.html;

    client_max_body_size 50M;

    # Backend API routes
    location ~ ^/(lead|contact|claim|note|call|meeting|email|task|user|policy|document|policydocument|emailtemplate)(/|$) {
        proxy_pass http://127.0.0.1:5000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }

    # Uploaded files
    location /uploads/ {
        alias /home/chd/surecrm/server/uploads/;
        expires 7d;
        access_log off;
    }

    # React SPA fallback
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Static assets caching
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff2?)$ {
        expires 30d;
        access_log off;
    }
}
```

فعال‌سازی سایت:

```bash
sudo ln -s /etc/nginx/sites-available/surecrm /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

> **نکته:** برای فعال‌سازی HTTPS، می‌توانید از [Let's Encrypt](https://letsencrypt.org/) و Certbot استفاده کنید.

#### ۹. ایجاد سرویس سیستم (Systemd Service)

برای اجرای خودکار سرور بک‌اند به‌عنوان یک سرویس سیستم، یک فایل سرویس systemd ایجاد کنید.

فایل `/etc/systemd/system/surecrm.service` را با محتوای زیر ایجاد کنید:

```ini
[Unit]
Description=SureCRM Backend Server
After=network.target mongod.service

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/home/chd/surecrm/server
ExecStart=/usr/bin/node index.js
Restart=on-failure
RestartSec=10
Environment=NODE_ENV=production

# Logging
StandardOutput=append:/var/log/surecrm/out.log
StandardError=append:/var/log/surecrm/error.log

[Install]
WantedBy=multi-user.target
```

فعال‌سازی و اجرای سرویس:

```bash
# ایجاد پوشه لاگ
sudo mkdir -p /var/log/surecrm
sudo touch /var/log/surecrm/out.log /var/log/surecrm/error.log
sudo chown www-data:www-data /var/log/surecrm

# ریلود systemd و فعال‌سازی سرویس
sudo systemctl daemon-reload
sudo systemctl enable surecrm
sudo systemctl start surecrm

# بررسی وضعیت سرویس
sudo systemctl status surecrm
```

#### ۱۰. تنظیم لاگ‌گردانی (Log Rotation)

برای مدیریت خودکار فایل‌های لاگ، یک فایل logrotate در `/etc/logrotate.d/surecrm` ایجاد کنید:

```
/var/log/surecrm/*.log {
    daily
    rotate 14
    size 50M
    missingok
    notifempty
    compress
    delaycompress
    copytruncate
    dateext
}
```

## مقدمه

SURECRM یک سیستم جامع مدیریت ارتباط با مشتری (CRM) است که به شما امکان مدیریت سرنخ‌ها، مخاطبین، بیمه‌نامه‌ها، تماس‌ها، جلسات، ایمیل‌ها و وظایف را می‌دهد. این راهنما به شما کمک می‌کند تا با تمام قابلیت‌های سیستم آشنا شوید.

---

## ورود به سیستم

1. مرورگر خود را باز کنید و به آدرس SureCRM مراجعه کنید.
2. صفحه ورود نمایش داده می‌شود.
3. نام کاربری و رمز عبور خود را وارد کنید.
4. دکمه **ورود** را کلیک کنید.
5. پس از ورود موفق، به داشبورد اصلی هدایت می‌شوید.

> **نکته:** اگر رمز عبور خود را فراموش کرده‌اید، با مدیر سیستم تماس بگیرید.

---

## داشبورد اصلی

پس از ورود، با داشبورد اصلی مواجه می‌شوید که شامل موارد زیر است:

### ویجت‌های داشبورد

| ویجت | توضیحات |
|-------|---------|
| **سرنخ‌ها (Leads)** | تعداد کل سرنخ‌های ثبت شده در سیستم |
| **مخاطبین (Contacts)** | تعداد کل مخاطبین ذخیره شده |
| **بیمه‌نامه‌ها (Policies)** | تعداد کل بیمه‌نامه‌های فعال |
| **وظایف (Tasks)** | تعداد کل وظایف تعریف شده |

### نمودارها و گزارش‌ها

- **بازدید وب‌سایت (Website Visits):** نمودار بازدیدهای وب‌سایت در ماه‌های مختلف
- **بازدیدهای فعلی (Current Visits):** توزیع جغرافیایی بازدیدکنندگان
- **وظایف در حال انجام (App Tasks):** لیست وظایف فعال
- **تاریخچه سفارشات (Order Timeline):** روند زمانی فعالیت‌ها
- **ترافیک وب‌سایت (Website Traffic):** منابع ترافیک ورودی

### نقش کاربری

- **مدیر (Admin):** دسترسی کامل به تمام بخش‌ها و مشاهده تمام رکوردها
- **کاربر عادی:** مشاهده فقط رکوردهای ایجاد شده توسط خود

## مدیریت کاربران

بخش مدیریت کاربران به مدیران سیستم امکان مدیریت حساب‌های کاربری را می‌دهد.

### دسترسی‌ها

- مشاهده لیست تمام کاربران
- افزودن کاربر جدید
- ویرایش اطلاعات کاربران موجود
- حذف کاربران
- تعیین نقش و سطح دسترسی

### مراحل مدیریت کاربران

1. از منوی سمت چپ، روی **کاربران (Users)** کلیک کنید.
2. برای افزودن کاربر جدید، دکمه **افزودن** را کلیک کنید.
3. اطلاعات کاربر را تکمیل کنید:
   - نام و نام خانوادگی
   - نام کاربری
   - رمز عبور
   - نقش کاربری
   - اطلاعات تماس
4. دکمه **ذخیره** را کلیک کنید.

---

## مدیریت سرنخ‌ها (Leads)

سرنخ‌ها (Leads) اطلاعات افرادی است که پتانسیل خرید یا همکاری را دارند.

### ویژگی‌ها

- ثبت سرنخ‌های جدید
- ویرایش اطلاعات سرنخ‌ها
- پیگیری وضعیت سرنخ‌ها
- دسته‌بندی سرنخ‌ها
- جستجو و فیلتر سرنخ‌ها

### مراحل افزودن سرنخ جدید

1. از منوی سمت چپ، روی **سرنخ‌ها (Leads)** کلیک کنید.
2. دکمه **افزودن سرنخ (Add Lead)** را کلیک کنید.
3. فرم زیر را تکمیل کنید:
   - **نام:** نام کامل سرنخ
   - **ایمیل:** آدرس ایمیل
   - **تلفن:** شماره تماس
   - **شرکت:** نام شرکت (در صورت وجود)
   - **وضعیت:** وضعیت فعلی سرنخ (جدید، در حال پیگیری، تبدیل شده، رد شده)
   - **منبع:** منبع شناسایی سرنخ
   - **توضیحات:** توضیحات اضافی
4. دکمه **ذخیره** را کلیک کنید.

### مشاهده جزئیات سرنخ

1. در لیست سرنخ‌ها، روی سرنخ مورد نظر کلیک کنید.
2. صفحه جزئیات سرنخ نمایش داده می‌شود.
3. می‌توانید اطلاعات تماس، تاریخچه فعالیت‌ها و یادداشت‌ها را مشاهده کنید.

## مدیریت مخاطبین (Contacts)

مخاطبین (Contacts) اطلاعات افرادی هستند که با آن‌ها در ارتباط هستید.

### تفاوت مخاطبین و سرنخ‌ها

- **سرنخ‌ها:** افراد یا شرکت‌هایی که پتانسیل همکاری دارند (در مرحله اولیه)
- **مخاطبین:** افرادی که ارتباط مستقیم با آن‌ها دارید (در مرحله پیشرفته‌تر)

### مراحل افزودن مخاطب جدید

1. از منوی سمت چپ، روی **مخاطبین (Contacts)** کلیک کنید.
2. دکمه **افزودن مخاطب (Add Contact)** را کلیک کنید.
3. فرم زیر را تکمیل کنید:
   - **نام و نام خانوادگی**
   - **ایمیل**
   - **تلفن**
   - **شرکت**
   - **سمت**
   - **آدرس**
   - **توضیحات**
4. دکمه **ذخیره** را کلیک کنید.

### مشاهده جزئیات مخاطب

1. در لیست مخاطبین، روی مخاطب مورد نظر کلیک کنید.
2. اطلاعات کامل، تاریخچه تماس‌ها، ایمیل‌ها و یادداشت‌ها نمایش داده می‌شود.

## مدیریت تماس‌ها (Calls)

بخش تماس‌ها برای ثبت و مدیریت تماس‌های تلفنی با FreePBX یکپارچه شده است.

### ویژگی‌ها

- ثبت تماس‌های ورودی و خروجی
- پخش ضبط‌های تماس
- مشاهده تاریخچه تماس‌ها
- مدیریت شماره‌های تلفن

### انواع تماس‌ها

| نوع تماس | توضیحات |
|----------|---------|
| **ورودی (Inbound)** | تماس‌هایی که به شما زده شده است |
| **خروجی (Outbound)** | تماس‌هایی که شما انجام داده‌اید |
| **پاسخ داده شده (Answered)** | تماس‌های پاسخ داده شده |
| **پاسخ داده نشده (Missed)** | تماس‌های پاسخ داده نشده |
| **اشغال (Busy)** | تماس‌هایی که خط اشغال بوده |
| **بدون پاسخ (No Answer)** | تماس‌هایی که پاسخ داده نشده |

### مراحل ثبت تماس جدید

1. از منوی سمت چپ، روی **تماس‌ها (Calls)** کلیک کنید.
2. دکمه **ایجاد تماس (Create Call)** را کلیک کنید.
3. فرم زیر را تکمیل کنید:
   - **شماره تلفن**
   - **نوع تماس** (ورودی/خروجی)
   - **وضعیت** (پاسخ داده شده، بدون پاسخ، اشغال)
   - **مدت زمان**
   - **یادداشت** (توضیحات تماس)
4. دکمه **ذخیره** را کلیک کنید.

### مشاهده جزئیات تماس

1. در لیست تماس‌ها، روی تماس مورد نظر کلیک کنید.
2. اطلاعات کامل تماس، شماره تلفن، مدت زمان و یادداشت‌ها نمایش داده می‌شود.
3. در صورت وجود، لینک پخش ضبط تماس نیز نمایش داده می‌شود.

---

## تماس‌های زنده (Live Calls)

بخش تماس‌های زنده امکان مشاهده و مدیریت تماس‌های فعال در لحظه را فراهم می‌کند.

### ویژگی‌ها

- مشاهده لیست تماس‌های در حال انجام
- مشاهده وضعیت هر تماس
- اطلاعات تماس‌گیرنده (Caller ID)
- مدت زمان تماس

### نحوه استفاده

1. از منوی سمت چپ، روی **تماس‌های زنده (Live Calls)** کلیک کنید.
2. لیست تماس‌های فعال نمایش داده می‌شود.
3. اطلاعات زیر برای هر تماس نمایش داده می‌شود:
   - شماره تماس‌گیرنده
   - وضعیت تماس
   - مدت زمان تماس
   - اپراتور پاسخ‌دهنده

---

## ضبط‌های تماس (Call Recordings)

بخش ضبط‌های تماس امکان دسترسی به فایل‌های ضبط شده تماس‌های تلفنی را فراهم می‌کند.

### ویژگی‌ها

- مشاهده لیست ضبط‌های تماس
- پخش آنلاین ضبط‌ها
- دانلود ضبط‌ها
- جستجو در ضبط‌ها

### نحوه استفاده

1. از منوی سمت چپ، روی **ضبط‌های تماس (Call Recordings)** کلیک کنید.
2. لیست ضبط‌های ذخیره شده نمایش داده می‌شود.
3. برای پخش، روی دکمه **پخش** کلیک کنید.
4. برای دانلود، روی دکمه **دانلود** کلیک کنید.

---

## مدیریت جلسات (Meetings)

بخش جلسات برای برنامه‌ریزی و مدیریت جلسات داخلی و با مشتریان استفاده می‌شود.

### ویژگی‌ها

- ایجاد جلسه جدید
- ویرایش جلسات موجود
- دعوت از شرکت‌کنندگان
- تنظیم یادآوری
- مشاهده تاریخچه جلسات

### مراحل افزودن جلسه جدید

1. از منوی سمت چپ، روی **جلسات (Meetings)** کلیک کنید.
2. دکمه **افزودن جلسه (Add Meeting)** را کلیک کنید.
3. فرم زیر را تکمیل کنید:
   - **عنوان جلسه**
   - **تاریخ و زمان شروع**
   - **تاریخ و زمان پایان**
   - **مکان**
   - **شرکت‌کنندگان**
   - **دعوت‌شدگان** (ایمیل)
   - **توضیحات/دستور جلسه**
4. دکمه **ذخیره** را کلیک کنید.

### مشاهده جزئیات جلسه

1. در لیست جلسات، روی جلسه مورد نظر کلیک کنید.
2. اطلاعات کامل جلسه، شرکت‌کنندگان و یادداشت‌ها نمایش داده می‌شود.

---

## مدیریت ایمیل‌ها (Emails)

بخش ایمیل‌ها برای ارسال و مدیریت ایمیل‌ها با مشتریان استفاده می‌شود.

### ویژگی‌ها

- ارسال ایمیل جدید
- مشاهده ایمیل‌های ارسالی و دریافتی
- جستجو در ایمیل‌ها
- استفاده از قالب‌های ایمیل

### مراحل ارسال ایمیل جدید

1. از منوی سمت چپ، روی **ایمیل‌ها (Emails)** کلیک کنید.
2. دکمه **ایجاد ایمیل (New Email)** را کلیک کنید.
3. فرم زیر را تکمیل کنید:
   - **گیرنده (To)**
   - **رونوشت (CC)** (اختیاری)
   - **رونوشت پنهان (BCC)** (اختیاری)
   - **موضوع (Subject)**
   - **متن ایمیل** (پشتیبانی از HTML)
   - **پیوست** (در صورت نیاز)
4. دکمه **ارسال** را کلیک کنید.

### استفاده از قالب‌های ایمیل

- می‌توانید از قالب‌های از پیش تعریف شده برای ایمیل‌های رایج استفاده کنید.
- برای ایجاد قالب جدید، به بخش **قالب‌های ایمیل** مراجعه کنید.

## مدیریت وظایف (Tasks)

بخش وظایف برای برنامه‌ریزی و پیگیری وظایف و کارها استفاده می‌شود.

### ویژگی‌ها

- ایجاد وظیفه جدید
- تعیین مسئول وظیفه
- تنظیم مهلت انجام
- پیگیری وضعیت وظایف
- اولویت‌بندی وظایف

### مراحل افزودن وظیفه جدید

1. از منوی سمت چپ، روی **وظایف (Tasks)** کلیک کنید.
2. دکمه **افزودن وظیفه (Add Task)** را کلیک کنید.
3. فرم زیر را تکمیل کنید:
   - **عنوان وظیفه**
   - **توضیحات**
   - **مسئول انجام**
   - **اولویت** (بالا، متوسط، پایین)
   - **وضعیت** (در انتظار، در حال انجام، تکمیل شده)
   - **مهلت انجام**
   - **دسته‌بندی**
4. دکمه **ذخیره** را کلیک کنید.

### وضعیت‌های وظیفه

| وضعیت | توضیحات |
|-------|---------|
| **در انتظار (Pending)** | وظیفه ایجاد شده اما هنوز شروع نشده |
| **در حال انجام (In Progress)** | وظیفه در حال انجام است |
| **تکمیل شده (Completed)** | وظیفه با موفقیت انجام شده |
| **لغو شده (Cancelled)** | وظیفه لغو شده است |

## قالب‌های ایمیل (Email Templates)

قالب‌های ایمیل به شما امکان می‌دهند ایمیل‌های از پیش تعریف شده ایجاد و مدیریت کنید.

### ویژگی‌ها

- ایجاد قالب جدید
- ویرایش قالب‌های موجود
- مشاهده و استفاده از قالب‌ها
- مدیریت متغیرهای پویا

### مراحل افزودن قالب جدید

1. از منوی سمت چپ، روی **قالب‌های ایمیل (Email Templates)** کلیک کنید.
2. دکمه **افزودن قالب (Add Template)** را کلیک کنید.
3. فرم زیر را تکمیل کنید:
   - **نام قالب**
   - **موضوع ایمیل**
   - **متن ایمیل** (پشتیبانی از HTML و متغیرها)
   - **دسته‌بندی**
4. دکمه **ذخیره** را کلیک کنید.

### استفاده از متغیرها

در قالب‌های ایمیل می‌توانید از متغیرهای پویا استفاده کنید:
- `{contact_name}` - نام مخاطب
- `{company_name}` - نام شرکت
- `{policy_number}` - شماره بیمه‌نامه
- `{date}` - تاریخ

- پس از اتمام کار، از سیستم خارج شوید.

## Logging (Administrator Guide)

SureCRM writes structured logs to `/var/log/surecrm`, split by subsystem:

| File | Subsystem | Content |
|---|---|---|
| `/var/log/surecrm/crm.log` | CRM | HTTP access, DB, SMTP mail, controllers |
| `/var/log/surecrm/pbx.log` | PBX | FreePBX / Asterisk AMI integration |
| `/var/log/surecrm/error.log` | both | every entry of level `error` and above |

### First-time setup

```bash
sudo ./server/scripts/setup-logdir.sh          # creates /var/log/surecrm + logrotate policy
sudo SERVICE_USER=www-data ./server/scripts/setup-logdir.sh   # custom service account
```

If the directory does not exist or is not writable (developer machines
without root), the application automatically falls back to `server/logs/`
and prints a one-time warning - it never crashes because of permissions.

### Configuration (environment variables)

| Variable | Default | Description |
|---|---|---|
| `LOG_DIR` | `/var/log/surecrm` | log directory override |
| `LOG_LEVEL` | `info` | minimum level (`error`, `warn`, `info`, `debug`) |
| `LOG_CONSOLE` | on (`false` to disable) | mirror entries to stdout |

File format is one JSON object per line (timestamp, level, subsystem, pid,
message, stack trace when applicable), which is easy to ingest into ELK /
Loki / CloudWatch. The console mirror is human-readable and colorized.

### Usage in code

```js
import { crm, pbx } from "../utils/logger.js";

crm.info("something happened", { leadId });
crm.error("failed to do X:", err);      // also lands in error.log
pbx.warn("AMI connection lost; will retry");
```

Rotation: `logrotate` rotates daily keeping 14 days (policy installed by
the setup script); winston's 20 MB size cap acts as an extra safeguard.
Unhandled promise rejections and uncaught exceptions are captured into
`error.log`; an uncaught exception terminates the process after logging.
